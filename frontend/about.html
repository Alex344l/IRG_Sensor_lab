ABOUT SENSOR LAB

Understanding the data behind the system

What is Sensor Lab?

Sensor Lab is a development and learning project focused on processing, analyzing, and visualizing sensor data.

The project uses simulated running-route datasets to recreate some of the types of data a real running system could collect, such as GPS coordinates, elevation, and timestamps.

The backend processes this raw data to calculate information such as distance, speed, pace, bearing, and elevation changes.

The goal is to build the software and data-processing foundations before connecting the system to physical sensors.

How It Relates to IRG

Sensor Lab is a supporting project for the larger IRG running project.

The long-term IRG concept involves a mixed-reality running system that can combine navigation, environmental information, running data, and optional interactive features.

Sensor Lab focuses on one part of that larger system: understanding and processing the underlying sensor data.

Why Build Sensor Lab?

Developing the data-processing side separately makes it possible to test calculations and visualizations before introducing the complexity of physical hardware.

Simulated datasets provide a controlled environment for experimenting with GPS processing, movement calculations, data visualization, and backend development.

Once the software foundation is established, the system can gradually move toward real sensor data.

Current Focus

Coordinates, routes, distance, and movement.

Motion

Speed, pace, bearing, and movement analysis.

Data

Processing, visualization, and time-series analysis.

Future Direction

As the project develops, Sensor Lab can move from simulated datasets toward real sensor data and eventually become part of the software foundation for the larger IRG system.
